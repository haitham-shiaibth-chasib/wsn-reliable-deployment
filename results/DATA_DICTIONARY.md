# Data dictionary

Manuscript references (tables, figures, equations, sections) follow the revised article (v1.3.0).

All files are comma-separated, UTF-8, with a header row. Lengths are in metres; coverage values,
probabilities and shares are fractions in [0, 1]. "Coverage" is always the share of raster cell
centres that lie within the sensing radius of at least one sensor (the raster resolution of each
experiment is given in `config/experiments.yaml`). Every number is produced by
`experiments/run_experiments.py` or `experiments/statistics.py`; nothing was edited by hand.

## Raw per-run files (`results/raw/`)

Every row is one independent simulation run (or one optimiser run). `seed` is the integer passed to
`numpy.random.default_rng`; `run` is the index of the draw within that generator, so a single run can
be regenerated by replaying runs `0 … run` of the same seed.

| File | Columns |
|---|---|
| `E2_runs.csv` | `r`, `N`, `seed`, `run`, `coverage` |
| `E6a_runs.csv` | `L`, `r`, `N`, `seed`, `run`, `coverage` |
| `E6b_runs.csv` | `L`, `r`, `N`, `seed`, `run`, `coverage` (one block per distinct N; the rules share blocks when they give the same N) |
| `E7a_runs.csv` | `Rc`, `N`, `seed`, `run`, `connected`, `no_isolated_node` |

| `E9_runs.csv` | `case`, `param`, `N`, `seed`, `run`, `value` (k-covered share, coverage, or mean detection probability); for failures also `connected` and `survivors` |
| `E10_runs.csv` | `method`, `N`, `seed`, `coverage`, `connected_rc_sqrt3r`, `coverage_sigma_0p2r`, `seconds`, `fitness_evals`, `nodes_used` |

## Layouts (`results/raw/layouts/`)

`E5_<rule>_r<radius>.csv` (Table 9), `E8_<lattice>_sigma<σ/r>r.csv` and `E16_<lattice>_sigma<σ/r>r.csv` (Table 10, the planned positions

run in Table 11).

## Version 1.3 additions (revision)

Manuscript references in this section follow the revised numbering. In every certification file a row is
one attempt of Algorithm 3: `attempt`, `seed` (fresh for every attempt), `runs` (2,000 drops), `met`,
`share`, `lower_bound` (one-sided Clopper-Pearson bound at level `alpha_attempt` = 0.05 / 10) and
`certified` (`lower_bound` ≥ 1 − δ). A design is certified at the first attempt that passes; the
certified value is repeated in `N_certified` (or `nodes_certified`, `kappa_certified`) and is empty when
no attempt passed.
